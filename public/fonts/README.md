# Self-hosted fonts

These WOFF2 files are copied from the Fontsource variable packages so the site
makes no runtime font requests.

| File                                       | Family              | Axes                                             | Source package                                   |
| ------------------------------------------ | ------------------- | ------------------------------------------------ | ------------------------------------------------ |
| `bricolage-grotesque-latin-variable.woff2` | Bricolage Grotesque | `wght` 200–800, `wdth` 75–100, `opsz` 14 default | `@fontsource-variable/bricolage-grotesque@5.3.0` |
| `geist-latin-variable.woff2`               | Geist               | `wght` 100–900                                   | `@fontsource-variable/geist@5.3.0`               |
| `jetbrains-mono-latin-variable.woff2`      | JetBrains Mono      | `wght` 100–800                                   | `@fontsource-variable/jetbrains-mono@5.3.0`      |

Each family is licensed under the SIL Open Font License 1.1. The matching
`*-OFL.txt` file sits beside the font and must stay with it.
